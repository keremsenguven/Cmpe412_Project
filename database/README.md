# Database - Smart Kitchen Project

## Purpose
This database stores:
- User inventory (ingredients in kitchen)
- Recipes and their ingredients
- Spoilage prediction results (ML)

## Files
- schema.sql → database structure
- seed.sql → sample data
- er-diagram.png → visual schema

## Tables
- users
- ingredients
- storage_locations
- user_inventory
- recipes
- recipe_ingredients
- spoilage_predictions

## Usage
Run schema.sql first, then seed.sql.
