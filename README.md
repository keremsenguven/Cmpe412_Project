# Database - Smart Kitchen Project

## Purpose

This database supports a smart kitchen / inventory management system.

The system allows users to:
- Manage ingredients in their kitchen inventory
- Store recipe data
- Receive recipe recommendations based on available ingredients
- Store spoilage prediction results generated by the ML model

---

## Database Technology

- **Engine:** MySQL
- **Database name:** `smart_kitchen_db`
- **Character set:** utf8mb4
- **Collation:** utf8mb4_unicode_ci

---

## Tables

### `users`
Stores registered users. Email is unique; only the password hash is stored.

| Column | Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| username | VARCHAR(100) | Username |
| email | VARCHAR(150) | Unique email address |
| password_hash | VARCHAR(255) | Hashed password |
| created_at | TIMESTAMP | Record creation time |

---

### `ingredients`
Stores all ingredients used in the system. Each ingredient belongs to one of 7 categories, which is used as a feature in the ML spoilage model.

| Column | Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| name | VARCHAR(100) | Unique ingredient name |
| category | ENUM | One of: `Liquid_Dairy`, `Fermented_Dairy`, `Hard_Cheese`, `Meat_Poultry`, `Vegetables`, `Fruits`, `Cooked_Meals` |
| default_unit | VARCHAR(30) | Default unit of measurement |
| created_at | TIMESTAMP | Record creation time |

---

### `storage_locations`
Defines physical storage locations (e.g. fridge, freezer). `avg_temperature` is used as an input feature for the ML model.

| Column | Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| name | VARCHAR(100) | Unique location name |
| avg_temperature | FLOAT | Average temperature in °C |

---

### `user_inventory`
Stores each user's current inventory items. Tracks each user's current ingredients, quantities, storage location, and expiry dates.

| Column | Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| user_id | BIGINT | FK → users (CASCADE DELETE) |
| ingredient_id | BIGINT | FK → ingredients (CASCADE DELETE) |
| quantity | DECIMAL(10,2) | Amount — must be > 0 (CHECK constraint) |
| unit | VARCHAR(30) | Unit of measurement |
| storage_location_id | BIGINT | FK → storage_locations (SET NULL on delete) |
| is_opened | BOOLEAN | Whether the product has been opened — affects spoilage rate |
| added_at | TIMESTAMP | Time added to inventory |
| expiry_date | DATE | Expiry date (nullable) |

---

### `recipes`
Stores recipe data. `ingredient_str` is a comma-separated free-text field used for ingredient-based recipe matching.

| Column | Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| name | VARCHAR(150) | Recipe name |
| ingredient_str | TEXT | Free-text ingredient list (comma-separated) |
| instructions | TEXT | Cooking instructions |
| created_at | TIMESTAMP | Record creation time |

> Recipes are not tied to any user — they form a global catalog accessible to all users.

---

### `spoilage_predictions`
Stores ML model output for each inventory item. `predicted_days` must be >= 0 (CHECK constraint).

| Column | Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| inventory_id | BIGINT | FK → user_inventory (CASCADE DELETE) |
| predicted_days | INT | Estimated remaining shelf life in days |
| model_name | VARCHAR(100) | Name of the ML model used (e.g. `xgboost_v1`) |
| created_at | TIMESTAMP | Prediction creation time |

---

## Relationships

```
users             1 ──< user_inventory
ingredients       1 ──< user_inventory
storage_locations 1 ──< user_inventory  (nullable)
user_inventory    1 ──< spoilage_predictions
recipes           (standalone — no FK relations)
```

---

## Indexes

| Index | Column | Purpose |
|---|---|---|
| idx_inventory_user | user_inventory.user_id | Fast inventory lookup by user |
| idx_inventory_ingredient | user_inventory.ingredient_id | Fast inventory lookup by ingredient |
| idx_inventory_storage | user_inventory.storage_location_id | Fast inventory lookup by location |
| idx_ingredients_category | ingredients.category | Filter ingredients by category |
| idx_predictions_inventory | spoilage_predictions.inventory_id | Fast prediction lookup by inventory item |
